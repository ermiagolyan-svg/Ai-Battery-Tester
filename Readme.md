# 🔋 Li-ion Battery Analyzer & Pack Builder (V6.8.2)
**Architecture Blueprint & AI Context**

## 📌 درباره پروژه
این پروژه یک سیستم پیشرفته‌ی ۳ کاناله بر پایه ESP32 برای تست، آنالیز، تریاژ هوشمند و کلاستربندی باتری‌های لیتیوم-یون (18650) است. این سیستم دارای قابلیت‌های سنجش ظرفیت، اندازه‌گیری مقاومت داخلی (IR) و مقاومت داینامیک (DCIR)، رابط کاربری تحت وب (Web Dashboard) با گرافیک سینک‌شده با نمایشگر فیزیکی، تولید فایل PDF، و الگوریتم یادگیری ماشین (K-Means) برای بالانس و ساخت پک باتری است.

---

## 🏗️ ساختار فایل‌ها و امضای کدها (Modules & Signatures)

### ۱. هسته و ماژول اصلی (`Ai-Battery-Tester.ino`)
*   **وظیفه:** ارکستراتور اصلی، راه‌اندازی سخت‌افزار (TFT, Touch, INA3221, LittleFS)، اتصال WiFi (با Fallback به حالت AP با نام `Portable-Tester`)، سنکرون‌سازی NTP و حلقه اصلی (Loop).
*   **ساختار داده کلیدی:** آرایه سراسری `Channel ch[3]` که تمام وضعیت‌ها (ولتاژ، جریان، ظرفیت، فاز، دیتای گراف و خطاها) را برای ۳ کانال در خود نگه می‌دارد.
*   **امضا:**
    *   `time_t nowEpoch()`
    *   `void setup()` / `void loop()`

### ۲. درایور سنسور (`sensor_ina3221.h`)
*   **وظیفه:** ارتباط I2C با ماژول ایزوله‌شده INA3221، تنظیم شنت (0.020 اهم) و محاسبه افت ولتاژ سیم‌ها (`WIRE_RESISTANCE_MOHM`).
*   **امضا:**
    *   `void setupINA3221()`
    *   `float readVoltage(uint8_t c)`
    *   `float readCurrent(uint8_t c)`

### ۳. کنترل کانال‌ها و ماشین حالت (`channel_control.h`)
*   **وظیفه:** قلب منطقی سیستم. کنترل رله‌ها/تخلیه (0.5A, 1.0A, 1.5A)، شارژ، سیستم ایمنی (Failsafe) برای دما/ولتاژ، مدیریت فازهای استراحت (Rest) و مدیریت منطق شارژ تکمیلی (Top-Up) از طریق متغیر `topUpRetries`.
*   **امضا:**
    *   `void setHwState(uint8_t c, ChannelState st)`
    *   `void measureIR(uint8_t c)`
    *   `void startChannel(uint8_t c, const String& name, ChannelState act)`
    *   `void startAuto(uint8_t c, const String& name, AutoMode mode)`
    *   `void stopChannel(uint8_t c)`
    *   `void sampleAll(unsigned long dt)`

### ۴. منطق تریاژ هوشمند (`triage_logic.h`)
*   **وظیفه:** اعمال پالس‌های جریانی پله‌ای، محاسبه سرعت ریکاوری ولتاژ، محاسبه مقاومت داینامیک (DCIR)، پیش‌بینی حرارتی و گریددهی باتری (A/B/C/D) بر اساس پروفایل‌های کاربری.
*   **امضا:**
    *   `void setTriageProfile(BatteryProfile profile)`
    *   `String gradeFromMohm(float mohm)`
    *   `void processTriage(uint8_t c)`

### ۵. رابط کاربری وب - API و سرور (`web_server_api.h`)
*   **وظیفه:** وب‌سرور غیرهمزمان ESP32، مدیریت Endpoint های RESTful.
*   **مسیرهای کلیدی:**
    *   `/data`: خروجی JSON از وضعیت زنده ۳ کانال (شامل متغیر `topup` برای شارژ تکمیلی).
    *   `/action` و `/stop`: دریافت دستورات کنترلی از فرانت‌اند.
    *   `/api/graph`: ارسال داده‌های ۲۴۰ نقطه‌ای برای رسم نمودار زنده.
    *   `/setprofile`: ذخیره تنظیمات در حافظه `Preferences`.

### ۶. فرانت‌اند - داشبورد زنده (`page_index.h`)
*   **وظیفه:** کدهای HTML/JS/CSS برای داشبورد اصلی. دارای طراحی ریسپانسیو، دکمه‌های کنترلی سریع (Action Grid)، آپدیت زنده با Fetch API، همگام‌سازی کامل رنگ وضعیت‌ها با نمایشگر TFT، رسم نمودار پیشرفته با محور ولتاژ و خروجی بومی گرافیک PNG.

### ۷. فرانت‌اند - تریاژ و ساخت پک هوشمند (`page_triage.h`)
*   **وظیفه:** خواندن تمام لاگ‌های CSV در مرورگر، اجرای الگوریتم K-Means Clustering بر اساس DCIR، IR و ظرفیت، و مرتب‌سازی و بالانس دقیق باتری‌ها برای ساخت پک (Pack Builder).

### ۸. فرانت‌اند - گزارش‌های انبوه (`page_logs.h`)
*   **وظیفه:** پیش‌نمایش متنی دیتابیس باتری‌ها و تولید فایل‌های خروجی PDF به صورت آفلاین در سمت کلاینت با استفاده از کتابخانه `jsPDF` (شامل رسم گراف برای هر باتری).

### ۹. فرانت‌اند - تنظیمات (`page_settings.h`)
*   **وظیفه:** کالیبراسیون آستانه‌های تریاژ، سنکرون کردن زمان RTC با مرورگر، و پاکسازی حافظه (LittleFS Wipe).

### ۱۰. سیستم ذخیره‌سازی (`logger_csv.h`)
*   **وظیفه:** مدیریت حافظه داخلی (LittleFS). ذخیره دیتای نهایی هر چرخه شامل ۲۴۰ نقطه گراف و نتایج تریاژ در فایل‌های `/log_chX.csv`.
*   **امضا:**
    *   `uint16_t getNextTestId(uint8_t ch)`
    *   `String generateAutoName(uint8_t ch)`
    *   `void saveCSV(uint8_t c)`

### ۱۱. رابط گرافیکی نمایشگر (`display_tft.h`)
*   **وظیفه:** رسم UI روی نمایشگر فیزیکی TFT دستگاه. استفاده از بافر Sprite برای جلوگیری از چشمک‌زدن. نمایش مینی‌گراف، تایمرها، وضعیت‌های داینامیک (نظیر `TOP-UP` و استراحت) و نتایج.
*   **امضا:**
    *   `void updateTFT()`

### ۱۲. سیستم اطلاع‌رسانی پیام‌رسان (`bale_bot.h`)
*   **وظیفه:** ارسال نوتیفیکیشن وضعیت باتری‌ها به صورت Async از طریق صف‌های FreeRTOS به پیام‌رسان بله، بدون درگیر کردن پردازش اصلی.
*   **امضا:**
    *   `void baleTask(void *pvParameters)`
    *   `void sendBaleNotification(String message)`
