# 🔋 Li-ion Battery Analyzer & Pack Builder (V6.8.2)
**Architecture Blueprint & AI Context**

## 📌 درباره پروژه
این پروژه یک سیستم پیشرفته‌ی ۳ کاناله بر پایه ESP32 برای تست، آنالیز، تریاژ هوشمند و کلاستربندی باتری‌های لیتیوم-یون (18650) است[cite: 1]. این سیستم دارای قابلیت‌های سنجش ظرفیت، اندازه‌گیری مقاومت داخلی (IR) و مقاومت داینامیک (DCIR)، رابط کاربری تحت وب (Web Dashboard) با گرافیک سینک‌شده با نمایشگر فیزیکی، تولید فایل PDF، الگوریتم یادگیری ماشین (K-Means) برای بالانس و ساخت پک باتری، و یک سیستم مدیریت وای‌فای اختصاصی و غیرهمزمان است[cite: 1].

---

## 🏗️ ساختار فایل‌ها و امضای کدها (Modules & Signatures)

### ۱. هسته و ماژول اصلی (`Ai-Battery-Tester.ino`)
*   **وظیفه:** ارکستراتور اصلی، راه‌اندازی سخت‌افزار (TFT, Touch, INA3221, LittleFS)، اتصال WiFi پویا (خواندن SSID و رمز از `Preferences` با Fallback به حالت AP با نام `Portable-Tester`)، سنکرون‌سازی NTP و حلقه اصلی (Loop)[cite: 1].
*   **ساختار داده کلیدی:** آرایه سراسری `Channel ch[3]` که تمام وضعیت‌ها (ولتاژ، جریان، ظرفیت، فاز، دیتای گراف و خطاها) را برای ۳ کانال در خود نگه می‌دارد[cite: 1].
*   **امضا:**
    *   `time_t nowEpoch()`[cite: 1]
    *   `void setup()` / `void loop()`[cite: 1]

### ۲. درایور سنسور (`sensor_ina3221.h`)
*   **وظیفه:** ارتباط I2C با ماژول ایزوله‌شده INA3221، تنظیم شنت (0.020 اهم) و محاسبه افت ولتاژ سیم‌ها (`WIRE_RESISTANCE_MOHM`)[cite: 1].
*   **امضا:**
    *   `void setupINA3221()`[cite: 1]
    *   `float readVoltage(uint8_t c)`[cite: 1]
    *   `float readCurrent(uint8_t c)`[cite: 1]

### ۳. کنترل کانال‌ها و ماشین حالت (`channel_control.h`)
*   **وظیفه:** قلب منطقی سیستم[cite: 1]. کنترل رله‌ها/تخلیه (0.5A, 1.0A, 1.5A)، شارژ، سیستم ایمنی (Failsafe) برای دما/ولتاژ، مدیریت فازهای استراحت (Rest) و مدیریت منطق شارژ تکمیلی (Top-Up) از طریق متغیر `topUpRetries`[cite: 1].
*   **امضا:**
    *   `void setHwState(uint8_t c, ChannelState st)`[cite: 1]
    *   `void measureIR(uint8_t c)`[cite: 1]
    *   `void startChannel(uint8_t c, const String& name, ChannelState act)`[cite: 1]
    *   `void startAuto(uint8_t c, const String& name, AutoMode mode)`[cite: 1]
    *   `void stopChannel(uint8_t c)`[cite: 1]
    *   `void sampleAll(unsigned long dt)`[cite: 1]

### ۴. منطق تریاژ هوشمند (`triage_logic.h`)
*   **وظیفه:** اعمال پالس‌های جریانی پله‌ای، محاسبه سرعت ریکاوری ولتاژ، محاسبه مقاومت داینامیک (DCIR)، پیش‌بینی حرارتی و گریددهی باتری (A/B/C/D) بر اساس پروفایل‌های کاربری[cite: 1].
*   **امضا:**
    *   `void setTriageProfile(BatteryProfile profile)`[cite: 1]
    *   `String gradeFromMohm(float mohm)`[cite: 1]
    *   `void processTriage(uint8_t c)`[cite: 1]

### ۵. رابط کاربری وب - API و سرور (`web_server_api.h`)
*   **وظیفه:** وب‌سرور غیرهمزمان ESP32، مدیریت Endpoint های RESTful[cite: 1].
*   **مسیرهای کلیدی:**
    *   `/data`: خروجی JSON از وضعیت زنده ۳ کانال (شامل متغیر `topup` برای شارژ تکمیلی)[cite: 1].
    *   `/action` و `/stop`: دریافت دستورات کنترلی از فرانت‌اند[cite: 1].
    *   `/api/graph`: ارسال داده‌های ۲۴۰ نقطه‌ای برای رسم نمودار زنده[cite: 1].
    *   `/setprofile`: ذخیره تنظیمات در حافظه `Preferences`[cite: 1].
    *   `/scanwifi` و `/setwifi`: اسکن شبکه‌های وای‌فای اطراف و ذخیره اطلاعات دسترسی جدید در حافظه سیستم.

### ۶. فرانت‌اند - داشبورد زنده (`page_index.h`)
*   **وظیفه:** کدهای HTML/JS/CSS برای داشبورد اصلی[cite: 1]. دارای طراحی ریسپانسیو، دکمه‌های کنترلی سریع (Action Grid)، آپدیت زنده با Fetch API، همگام‌سازی کامل رنگ وضعیت‌ها با نمایشگر TFT، رسم نمودار پیشرفته با محور ولتاژ و خروجی بومی گرافیک PNG[cite: 1].

### ۷. فرانت‌اند - تریاژ و ساخت پک هوشمند (`page_triage.h`)
*   **وظیفه:** خواندن تمام لاگ‌های CSV در مرورگر، اجرای الگوریتم K-Means Clustering بر اساس DCIR، IR و ظرفیت، و مرتب‌سازی و بالانس دقیق باتری‌ها برای ساخت پک (Pack Builder)[cite: 1].

### ۸. فرانت‌اند - گزارش‌های انبوه (`page_logs.h`)
*   **وظیفه:** پیش‌نمایش متنی دیتابیس باتری‌ها و تولید فایل‌های خروجی PDF به صورت آفلاین در سمت کلاینت با استفاده از کتابخانه `jsPDF` (شامل رسم گراف برای هر باتری)[cite: 1].

### ۹. فرانت‌اند - تنظیمات (`page_settings.h`)
*   **وظیفه:** اسکن و تغییر شبکه وای‌فای دستگاه، کالیبراسیون آستانه‌های تریاژ، سنکرون کردن زمان RTC با مرورگر، و پاکسازی حافظه (LittleFS Wipe)[cite: 1].

### ۱۰. سیستم ذخیره‌سازی (`logger_csv.h`)
*   **وظیفه:** مدیریت حافظه داخلی (LittleFS)[cite: 1]. ذخیره دیتای نهایی هر چرخه شامل ۲۴۰ نقطه گراف و نتایج تریاژ در فایل‌های `/log_chX.csv`[cite: 1].
*   **امضا:**
    *   `uint16_t getNextTestId(uint8_t ch)`[cite: 1]
    *   `String generateAutoName(uint8_t ch)`[cite: 1]
    *   `void saveCSV(uint8_t c)`[cite: 1]

### ۱۱. رابط گرافیکی نمایشگر (`display_tft.h`)
*   **وظیفه:** رسم UI روی نمایشگر فیزیکی TFT دستگاه[cite: 1]. استفاده از بافر Sprite برای جلوگیری از چشمک‌زدن[cite: 1]. نمایش مینی‌گراف، تایمرها، وضعیت‌های داینامیک (نظیر `TOP-UP` و استراحت) و نتایج[cite: 1].
*   **امضا:**
    *   `void updateTFT()`[cite: 1]

### ۱۲. سیستم اطلاع‌رسانی پیام‌رسان (`bale_bot.h`)
*   **وظیفه:** ارسال نوتیفیکیشن وضعیت باتری‌ها به صورت Async از طریق صف‌های FreeRTOS به پیام‌رسان بله، بدون درگیر کردن پردازش اصلی[cite: 1].
*   **امضا:**
    *   `void baleTask(void *pvParameters)`[cite: 1]
    *   `void sendBaleNotification(String message)`[cite: 1]
