# 🔋 Li-ion Battery Analyzer & Pack Builder (V6.8.2)
**Architecture Blueprint & AI Context**

## 📌 درباره پروژه
این پروژه یک سیستم پیشرفته‌ی ۳ کاناله بر پایه ESP32 برای تست، آنالیز، تریاژ هوشمند و کلاستربندی باتری‌های لیتیوم-یون (18650) است. این سیستم دارای قابلیت‌های سنجش ظرفیت، اندازه‌گیری مقاومت داخلی، داشبورد وب زنده (دو زبانه و ریسپانسیو) با کنترل‌های هوشمند، تولید فایل PDF و الگوریتم یادگیری ماشین (K-Means) برای بالانس پک باتری می‌باشد.

---

## 🏗️ ساختار فایل‌ها و امضای کدها (Modules & Signatures)

### ۱. هسته و ماژول اصلی (`Ai-Battery-Tester.ino`)
*   **وظیفه:** ارکستراتور اصلی، راه‌اندازی سخت‌افزار (TFT, Touch, LittleFS) و حلقه اصلی (Loop).
*   **ساختار کلیدی:** `Channel ch[3]` برای نگهداری وضعیت زنده.
*   **امضا:** `void setup()` / `void loop()` / `time_t nowEpoch()`

### ۲. درایور و سنسور (`sensor_ina3221.h`)
*   **وظیفه:** ارتباط I2C با ماژول سنسور (برد CJMCU-3221 با پین‌های ورودی و VPU ایزوله و مجزا) و تنظیم شنت.
*   **امضا:** `void setupINA3221()` / `float readVoltage(uint8_t c)` / `float readCurrent(uint8_t c)`

### ۳. کنترل کانال‌ها و ماشین حالت (`channel_control.h`)
*   **وظیفه:** کنترل رله‌ها، سیستم ایمنی، مدیریت منطق شارژ تکمیلی (`topUpRetries`) و فازهای استراحت.
*   **امضا:** `void setHwState()` / `void startChannel()` / `void startAuto()` / `void stopChannel()`

### ۴. منطق تریاژ هوشمند (`triage_logic.h`)
*   **وظیفه:** محاسبه مقاومت داینامیک (DCIR) و گریددهی باتری‌ها.
*   **امضا:** `void setTriageProfile(BatteryProfile profile)` / `void processTriage(uint8_t c)`

### ۵. API و وب‌سرور (`web_server_api.h`)
*   **وظیفه:** وب‌سرور غیرهمزمان ESP32 و مدیریت Endpointهای RESTful.
*   **مسیرهای کلیدی:** `/data` (ارسال متغیرهای state, topup و...)، `/action`، `/api/graph` و `/setprofile`.

### ۶. فرانت‌اند - داشبورد زنده (`page_index.h`)
*   **وظیفه:** رابط کاربری (HTML/JS/CSS) دو زبانه و ریسپانسیو. دارای پنل تنظیمات سراسری (Auto/Manual)، مودال‌های پاپ‌آپ و گرید ۵ دکمه‌ای هوشمند با آپدیت زنده (Fetch API).

### ۷. فرانت‌اند - تریاژ و ساخت پک (`page_triage.h`)
*   **وظیفه:** خواندن لاگ‌های CSV در مرورگر و کلاستربندی الگوریتم K-Means بر اساس DCIR، IR و ظرفیت برای ساخت پک متقارن (چینش سری سلول‌ها با قطب‌های منفی در پایین).

### ۸. فرانت‌اند - گزارش‌های انبوه (`page_logs.h`)
*   **وظیفه:** تولید فایل‌های خروجی PDF در سمت کلاینت با کتابخانه `jsPDF`.

### ۹. فرانت‌اند - تنظیمات (`page_settings.h`)
*   **وظیفه:** پنل مدیریت دو زبانه کلاینت‌ساید با `localStorage` شامل تنظیمات WiFi، سنکرون زمان RTC و پاکسازی LittleFS.

### ۱۰. سیستم ذخیره‌سازی (`logger_csv.h`)
*   **وظیفه:** مدیریت حافظه داخلی و ذخیره دیتای نهایی در `/log_chX.csv`.
*   **امضا:** `void saveCSV(uint8_t c)` / `String generateAutoName(uint8_t ch)`

### ۱۱. رابط گرافیکی نمایشگر (`display_tft.h`)
*   **وظیفه:** رسم UI روی TFT فیزیکی به کمک بافر Sprite.
*   **امضا:** `void updateTFT()`

### ۱۲. ربات پیام‌رسان (`bale_bot.h`)
*   **وظیفه:** ارسال نوتیفیکیشن وضعیت باتری‌ها به صورت Async از طریق صف‌های FreeRTOS.
*   **امضا:** `void baleTask(void *pvParameters)`
